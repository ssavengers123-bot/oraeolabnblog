AEO 검증 — AI 브리핑이 뜨는 검색어로 제목 정하기

글마다 검색어 2개(키워드형·질문형)를 네이버에서 직접 검색해 AI 브리핑이 뜨는지 기록합니다. 기록하면 캘린더·시작하기의 제목과 원고 프롬프트가 자동으로 바뀝니다. 결과는 이 브라우저에 저장됩니다.

검사 방법 · PC 결과는 이미 들어 있음, 모바일만 직접 확인
  1. PC 결과는 2026-10-15에 자동으로 확인해 표에 넣어 두었습니다 (search.naver.com 통합검색 76개 검색어). 23개 검색어에서 AI 브리핑이 떴고, 그중 3개 검색어에서는 오래오랩 글이 이미 출처로 인용됐습니다.
  2. 모바일 네이버 앱에서 같은 검색어를 검색해 결과가 다르면 아래 선택을 바꿔 주세요. 직접 고른 값이 PC 값보다 우선합니다.
  3. 결과 맨 위나 중간에 'AI 브리핑' 상자가 보이면 뜸, 끝까지 내려도 없으면 안 뜸입니다. 'PC: 뜸 · 출처'에 적힌 블로그들이 지금 인용되는 경쟁 글입니다.
  4. 뜨면 상자 안에 인용된 출처(블로그·사이트 이름)를 메모 칸에 적습니다. 경쟁 상대이자 참고할 글입니다.
  5. 검색어 하나라도 '뜸'이면 그 글은 AEO 글로 다룹니다. 질문형만 뜨면 제목이 질문형으로 바뀝니다. 둘 다 '안 뜸'이면 일반 검색 노출(SEO)만 기대하고, 4주 뒤 다시 검사합니다.
  6. 개인화 영향이 있으니 가능하면 두 사람이 각자 확인하고, 검사한 날짜는 자동으로 기록됩니다.

세팅 순서 (새 클라이언트, 약 반나절)
  1. 데이터 받기 — 네이버 블로그 통계에서 조회수·순방문자·성연령별 분포(최근 1~3개월)·유입분석(최근 2개 시점)·조회수 순위, 글 목록 캡처(누적 조회). 자사몰·스토어 유입 데이터가 있으면 함께.
  2. 현황 진단 — 발행 공백, 트래픽 추이, 유입 키워드를 관계·상황·목적으로 분류해 타겟을 정의. 유효 지표만 하이라이트한 1장 요약을 만들어 클라이언트와 방향 합의.
  3. 운영 회의 결정 정리 — 목적(전환/문의/인지), 다룰 주제와 다루지 않을 주제, 구매 링크 정책, 채널 분리(자사몰 글 미러링 여부), 카테고리 이름 변경 가능 여부, 발행 주기.
  4. 키워드 조사 — 후보 30~40개를 마피아넷·네이버 키워드도구로 조회(월 검색수 PC/모바일, 월 블로그 발행수, 포화도, 광고 경쟁). 구매 연결성 → 검색 수요 → 경쟁 순으로 상·중·하·제외.
  5. AEO 검증 — 글마다 키워드형·질문형 검색어 2개를 정하고 아래 절차로 PC 자동검증. 뜨는 주제를 앞으로, 질문형만 뜨면 질문형 제목으로.
  6. 프롬프트 실행 — 아래 프롬프트의 [ ] 칸을 채워 AI에 넣고 HTML을 받음. 예시 원고 1개로 점검기가 동작하는지 확인.
  7. 공유·운영 — 아티팩트로 공유. 4주마다 유입분석을 다시 받아 키워드 맵과 AEO 검증을 갱신.
점검기 생성 프롬프트 (복사해서 [ ] 채우기)
AEO(네이버 AI 브리핑) PC 자동검증 절차
  1. Apify에서 hgservices/naver-search-scraper를 실행합니다. 입력: queries=검색어 배열, searchType=integrated, mobileResults=false(PC), saveHtml=true, maxPagesPerQuery=1, maxConcurrency=3. 검색어 70개에 약 6분, 1달러 미만.
  2. Key-value store에 저장된 각 검색어의 HTML을 받습니다. (네이버는 직접 접속이 막히는 환경이 많아 스크래퍼를 거칩니다)
  3. HTML에 fds-aib-header-title-text 문자열이 있으면 AI 브리핑이 뜬 것입니다.
  4. 답변이 서버에 포함된 경우 "copy":"…"에 답변 전문(정보출처 목록 포함), "sources":[{"gdid"…에 출처 배열(sourceName, platform, title, url, dateText)이 있습니다. 없으면 '실시간 생성형'으로 표시만 합니다.
  5. 출처에 클라이언트 도메인·블로그명이 있으면 '인용됨'으로 표시합니다. 결과를 페이지의 AEO_PC 데이터에 넣습니다.
  6. 모바일은 mobileResults=true로 같은 방식이 되는지 먼저 1~2개로 확인한 뒤 돌립니다. 4주마다 재검사합니다.
