# 오래오랩 네이버 블로그 점검기

네이버 SEO·AEO 기준과 운영 회의 결정으로 블로그 원고를 발행 전에 점검하는 도구입니다. HTML 파일 하나로 동작하며 서버가 필요 없습니다.

## 사용
- `index.html`을 내려받아 더블클릭하면 브라우저에서 열립니다.
- GitHub Pages를 켜면 주소로 바로 열 수 있습니다. (Settings → Pages → Branch: main / root)

## 탭 구성
| 탭 | 하는 일 |
|---|---|
| 시작하기 | 5단계 작업 순서, 이번 주 글 자동 표시, 발행 전 체크리스트 |
| 캘린더 | 20주 발행 목록, 글별 키워드·카테고리·연결 제품, AI 원고 작성 프롬프트 |
| 이미지 | 글별 이미지 7장 샷리스트와 제작 프롬프트 |
| 글 점검 | 원고 붙여 넣기 → 점수·판정·항목별 결과, UTM 생성 |
| 운영 기준 | 회의 결정, 작성 기준, 표현 기준, 카테고리 |
| 키워드 맵 | 키워드 우선순위 (검색량·발행량) |
| AEO 검증 | 검색어별 네이버 AI 브리핑 노출 여부 (PC 자동검증 + 모바일 직접 확인) |
| 재사용 템플릿 | 다른 클라이언트용으로 다시 만드는 프롬프트와 절차 |

## 주의
- 점검기에 입력한 값(원고, AEO 직접 확인)은 브라우저에만 저장되고 이 파일에는 저장되지 않습니다.
- 데이터(캘린더, 키워드, AEO 결과)는 `index.html` 안 `<script>` 상단의 `CAL`, `ORDER`, `IMG`, `AEOQ`, `AEO_PC` 에 있습니다.
